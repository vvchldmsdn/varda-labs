# 경제 상태 조건부 시뮬레이션

`model=economic`이 기본이며 `model=bootstrap`으로 기존 과거 공동 수익률 재표본 모형을 선택할 수 있다. 모형 선택은 메인 경로, 비중 실험, 과거 검증, 모형·데이터 패널에 함께 적용한다. 알 수 없는 값이나 복수 model 값은 기본값으로 대체하지 않는다.

## 기능의 해석

사용자가 요청한 것은 과거 포트 수익률 한 개만 다시 뽑는 방식보다 넓은, 경제변수와 보유 종목의 공동 확률 경로다. 이 구현에서는 현재 평가액으로 정한 시작 비중과 최신 사용 가능한 경제 수준에서 출발한다. 보유 종목의 원화 가격 성장 경로에는 각 지표에 대한 회귀 민감도와 종목 간 상관 잔차를 반영한다. 화면의 시작값 100은 이 현재 구성을 정규화한 값이지, 과거의 실제 개인 계좌 잔액이 아니다.

비중 변경은 경로를 거꾸로 푸는 유일한 해가 아니라, 같은 경로에서 목적값을 비교하는 제약 탐색이다. 중앙 수익률을 높이는 목표, 하위 결과를 방어하는 목표, 둘을 절충하는 목표가 서로 다르다. 손실 빈도를 함께 표시하지만, 손실 빈도 최소화나 특정 수익률 달성확률 최대화를 직접 푼 것으로 설명하지 않는다. 현실의 수익 확률은 모형 오차와 시장 변화까지 포함하므로 모의 경로의 빈도와 동일하다고 확정할 수 없다.

방법론 참고로 [MSCI의 다자산 요인모형](https://www.msci.com/data-and-analytics/factor-investing/multi-asset-class-factor-models)은 자산군 사이 위험·수익 동인을 연결하는 접근을 설명한다. [MSCI의 Monte Carlo 사례](https://www.msci.com/research-and-insights/blog-post/retire-in-monte-carlo-simulating-retirement-outcomes)는 변동성·상관관계와 자산 구성을 이용해 시나리오별 경로를 비교한다. 이는 접근의 참고 자료이며 이 서비스 모형의 예측 성능을 입증하는 근거가 아니다.

## 연결과 데이터 권위

원서비스는 `gyeol-fin/src/pages/Portfolio.jsx`에서 연결되는 `src/components/simulation/useSimulationValidationRun.js`의 실제 작업 흐름과 `base44/functions/runHybridPortfolioSimulation/entry.ts`를 검토했다. 해당 inline 계산에는 양수인 금리도 로그 비율로 변환하는 분기와 자산 공분산 중심의 경로 생성, bootstrap 중앙값에 드리프트를 맞추는 부분이 있다. 기능 의도는 참고하되 이 구현을 그대로 복사하거나 오래된 독립 Simulation 화면을 권위로 삼지 않는다. Varda에서는 변수 단위, 경제 상태 갱신, 종목별 조건부 수익률, 별도 확인 경로를 명시한 아래 엔진을 사용한다.

- 서버의 인증된 tenant/scope → 기존 owner return matrix → `simulation-owner-economic-research.ts` → `simulation-economic-state-model.ts` 순서다.
- 시작 비중은 현재 평가액의 계산 가능 부분을 100%로 정규화한다. 종목별 입력은 **KRW 투자자 수익률**이다. 환율을 자산 성장값에 다시 곱하지 않는다.
- 공용 저장 자료의 USD/KRW, 미국 10년 국채금리, 미국 10년−2년 금리차만 사용한다. 각국 정책금리 전체, 뉴스, 독립 주가지수 요인은 지원한다고 표시하지 않는다. 보유 종목 가격의 확률 경로는 각 종목의 공동 수익률과 회귀 민감도·상관 잔차에서 생성한다.
- 경제 상태는 요청 기준일보다 엄격히 이전 공표값을 사용한다. 공표일·관측일·대상기간 종료일의 최대 경과가 7일을 넘으면 현재 상태로 채택하지 않는다. 기준일이 지정되지 않으면 현 서비스 기록 기준일을 적용하며, 가격 이력 종료일과 경제 상태 기준일을 각각 표시한다.
- 최대 90개 수익률 중 전후 경제 상태가 모두 유효한 최소 45개 관측이 필요하다. 결측·오래된 현재 상태·유효하지 않은 행렬을 다른 모형이나 가짜 값으로 대체하지 않는다.
- 렌더링 및 상세 조회는 provider 호출·DB 쓰기를 하지 않는다. 기존 공용 수집을 재사용한다. 종목별 원시 성장 배열과 경제 상태 배열은 서버 요청 안에서만 보유한다. 메인 차트에는 현재 비중으로 합산한 포트폴리오 경로만 전달하고, 종목별 원시 배열은 API/Client Component에 전달하지 않는다.

## 확률 경로

상태는 `x=[log(USD/KRW), US10Y(%), US10Y−2Y(%p)]`이다. 학습 쌍은 **이전 상태와 다음 변화**이며 다음 시점 상태를 설명변수로 쓰지 않는다. FX는 로그 변화, 금리와 금리차는 %p 변화다.

1. EWMA 0.97로 인자·자산 평균 및 공분산을 추정한다. 인자 공분산 비대각 15%, 잔차 25% 축소와 ridge 회귀를 적용한다. `alpha=mean(y)−beta mean(deltaF)`이므로 과거 평균을 중복 가산하지 않는다.
2. 과거 상태를 median/MAD로 정규화하고 현재 모의 상태와의 거리에 Gaussian kernel·EWMA 가중치를 적용한다. 유효 표본 수와 최근접 상태 거리로 조건부 평균의 반영률을 감쇠한다. 반영률 상한은 0.5다. 수치·정확한 식은 엔진 policy와 화면의 수식 설명을 기준으로 한다.
3. 매 단계 조건부 평균은 다시 구하지만 **공분산·회귀계수는 학습창 추정값으로 고정**한다. 작은 이웃 표본으로 조건부 공분산까지 다시 추정하지 않는다.
4. `deltaF = conditionalMean(x) + Lf z sqrt((7−2)/chiSquare(7))`, `y=alpha+beta deltaF+Le epsilon`. 인자 충격은 공동 Student-t, 잔차는 종목 간 상관을 가진 Gaussian이며 두 충격 묶음은 독립이다.
5. `x_next=x+deltaF`, `G_i,next=G_i exp(y_i)`, `NAV=sum(w_i G_i)`. FX 수준은 지수 변환으로 양수이며 금리의 음수 가능성을 임의로 잘라내지 않는다. 초기 비중 배분 후 보유수량 유지 방식이다.

1,000개 완전 경로로 분포와 실제 경로 MDD를 계산한다. 메인 차트는 합산한 포트폴리오 경로 1,000개를 모두 표시한다. 비중 후보 차트는 표시용 표본 12개와 전체 경로의 분위수를 사용하며, 표본선 수는 확률 계산의 분모 1,000을 바꾸지 않는다. 관측 범위 밖으로 이동한 모의 단계 비율과 시작 상태 유효 표본·반영률을 공개한다.

Student-t에는 유한한 적률생성함수가 없으므로([Western University 확률통계 강의](https://fisher.stats.uwo.ca/faculty/kulperger/SS3657-2016/Handouts/MGF.pdf)), 이 모형의 비영 요인 노출을 지수 변환한 가격에 유한한 이론적 평균이 있다고 가정하지 않는다. 이는 해당 분포를 가격 성장식에 적용했을 때의 수학적 해석이다. 유한 1,000경로의 표본평균과 모집단 기대수익을 구분하고, 후보 탐색은 P50·P10을 사용한다. 꼬리를 임의로 자른 뒤 원래 모형인 것처럼 표시하지 않는다.

## 비중 실험과 검증

`simulation-owner-economic-candidates.ts`는 동일한 자산 성장 배열을 모든 비중에 재사용한다. 기존 optimizer의 bootstrap 입력 어댑터는 유지하고 별도 인자 경로 어댑터로 공통 탐색에 연결한다.

- 목적: P50 수익률, P10 수익률, `(P50+P10)/2`. 평균수익·MDD·양수 수익 확률을 직접 최적화한 것으로 설명하지 않는다.
- long-only 합계 100%, 종목 상한 `max(35%, 현재 최대 비중)`, 편도 교체 20%, 비원화 표시 자산 노출 변화 10%p.
- 5%p → 2.5%p → 1%p 이동, 크기별 최대 4회 국소 탐색. 전역 최적해를 증명하지 않는다.
- 성능을 위해 각 탐색 반복의 기준 NAV를 한 번 구하고 `NAV후보 ≈ NAV기준 + 이동비중 × (받는종목성장 − 주는종목성장)`으로 명확히 불리한 후보를 먼저 제외한다. 반올림 오차 경계와 유력 후보는 원래 전체 가중합으로 다시 비교한다. 최종 공개 지표도 전체 계산을 쓰므로 탐색·동점·제약의 의미를 바꾸지 않는다. 이전 500경로 정책 당시의 64종목·500경로 로컬 합성 대조에서 11.49초 → 2.17초 및 결과 전체 일치를 확인했다. 1,000경로에서의 측정이나 운영 응답시간 측정은 아니며, 수치 경계 입력은 전체 계산으로 돌아가므로 속도 개선이 보장되지 않는다.
- 짝수 경로 500개 탐색, 홀수 500개 확인 양쪽에서 목적값이 개선된 후보만 표시한다. 같은 모형 안의 확인이며 실제 미래 검증이 아니다.
- `simulation-owner-economic-validation.ts`: 최대 3개 비중첩 구간, 90개 학습 → 21개 실제 결과. 각 학습창 안에서 모형 추정과 후보 탐색을 끝낸다. 이후 결과로 후보를 선별하지 않고 악화한 후보도 표시한다. 같은 학습창의 기존 무조건 요인 모형과 구간 포함률·중앙값 오차·손실 Brier 점수를 비교한다.

현재 보유 구성을 과거에 적용하는 연구다. 실제 과거 보유 포지션, 최초 공표 시각과 개정 전 값이 없으므로 엄격한 point-in-time 백테스트는 아니다. 21단계 진단이나 소수 구간으로 63·126단계 예측력 개선을 주장하지 않는다. 거래 비용·세금·현금 이자·중간 입출금은 제외하며 주문이나 목표비중 저장은 실행하지 않는다.
