# 핵심 흐름 사용자 검증

2026-11-05 개발 후 검증 계획. 아직 사용자 반응이나 지불 의향이 확인된 결과는 아니다.

## 먼저 확인할 제품 조건

- 같은 계좌·통화에서 평가액, 원형 비중, 상세 목록이 같은 평가 근거를 사용한다.
- 일부 자산을 평가할 수 없으면 확인된 소계와 제외된 자산을 구분한다.
- 수동 갱신은 처음 정한 대상을 끝까지 확인하며, 화면 복귀 후에도 진행 상태를 확인할 수 있다.
- 가격 기준 시각과 조회 시각은 별개다. 공용 공급자 호출을 동반하는 운영 실험은 별도로 범위를 확인한다.
- 첫 입력은 현재 평가금액이다. 매입원가·실제 거래·과거 수익률을 생성하지 않는다.
- 직접 A/B 배분은 같은 투자금과 현재 평가 기준으로 비교한다. 남은 투자금과 목표에서 남은 차이를 보여준다.

## 소규모 사용성 확인

참여자는 약 10명으로 시작한다. 보유자산 규모나 금융정보 공개를 요구하지 않고 예시 금액으로도 참여할 수 있다. 화면 녹화나 캡처 수집은 별도 동의를 받는다.

| 과제 | 관찰할 것 | 기록할 결과 |
| --- | --- | --- |
| 도움 없이 자산 입력 → 결과 확인 → 가입·저장 | 수량/단가/평가액 혼동, 가져오기 확인, 가입 후 입력 유지 | 성공 여부, 막힌 위치, 도움 요청 여부 |
| 현재 구성 확인 | 총액·제외 자산·가장 큰 비중을 설명할 수 있는지 | 본인이 찾은 유용한 정보 한 가지 |
| 목표 입력 → A/B 추가투입 비교 | 같은 투자금, 남은 돈, 목표와의 차이를 이해하는지 | 선택한 안과 선택 이유, 잘못 이해한 표현 |
| 며칠 뒤 재방문 | 이전 입력·기록을 찾고 다시 비교하는지 | 자발적 재방문 여부와 목적 |

완료율만 보지 않고 막힌 화면과 원인을 함께 기록한다. 10명은 기능 발견과 사용성 문제를 찾기 위한 규모이며 시장 수요나 적정 가격을 확정하는 근거가 아니다.

## 유료 범위 가설

기본 자산 관리·현재 구성은 무료, 여러 투자안 비교·장기 기록·고급 분석은 유료 후보로만 둔다. 사용 후 없어지면 아쉬운 기능과 지불 의향을 묻되, 답변을 실제 구매로 해석하지 않는다.

이 문서는 결제·유료 제한·종목 추천·실제 주문·운영 배포를 추가하지 않는다. 실제 피드백이 모이면 문제 빈도와 사용 맥락을 기준으로 다음 범위를 결정한다.
