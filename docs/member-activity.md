# 회원 활동 관리

관리자는 서버에서 확인한 Neon 로그인 사용자 중 이메일 인증이 완료된 `vvchldmsdn@gmail.com`이다. `/portfolio/manage`의 회원 활동 관리 링크 또는 `/management/members`를 사용한다. 일반 app_users.role과 금융 tenant 권한은 변경하지 않는다. 인증 실패·불일치·비활성 계정은 보고서 SQL 호출 전에 거부한다.

- 회원 목록은 app_users 활성 owner가 연결된 계정이다. 인증만 가입하고 아직 owner가 연결되지 않은 계정은 포함하지 않는다. Neon Auth 전체 가입자 수와 같다고 해석하지 않는다.
- 로그인한 활성 회원의 허용된 기능 화면 방문만 기록한다. 익명/데모/인증/관리자 화면은 제외한다.
- 브라우저는 feature enum 하나만 전송한다. 이름·이메일·owner는 서버 세션에서 얻는다. URL/query, 금액, 종목, 계좌, IP, 토큰은 기록하지 않는다.
- 마지막 기록과 30분 이상 간격이면 새 방문. 동일 기능의 60초 이내 요청은 무시한다. owner advisory lock과 ReadCommitted transaction으로 동시 요청을 직렬화한다.
- 보고서의 방문·활동일·기능 조회와 재방문(방문 2회 이상)은 한국 날짜 기준 최근 90일이다. 기능 조회는 계산 실행/완료가 아니다. 고유 사용자 전환율이나 정확한 로그인 횟수로 해석하지 않는다.
- 최근 접속은 마지막 수집 시각이다. 로그인된 채 오래 열린 화면의 모든 클릭을 감시하지 않는다. 과거 데이터 소급 없음. 수집 전 회원은 짧은 내부 ID와 미집계 상태로 표시한다. Naver는 현재 session 계약에 검증된 이메일이 없으므로 내부 ID로 구분한다.
- 일별 기능 기록은 다음 활동 transaction에서 90일 범위를 벗어나면 정리한다. 활동이 없으면 정리 시점이 늦어질 수 있다. 프로필과 최근 접속은 계정 수명 동안 유지하고 app_users 삭제 시 FK cascade로 함께 삭제한다.
- 두 테이블은 ENABLE/FORCE RLS, PUBLIC/varda_tenant_app 권한 없음, tenant 정책 없음이다. 기존 서버 privileged connection을 검증된 DAL 경계 안에서만 쓴다. tenant 재산 접근 권한은 부여하지 않는다.
- 테이블 추가는 0047 migration이며 기존 자산/인증 데이터와 무관하다. UI에서 운영자 이메일을 입력하거나 클라이언트 role을 조작해 접근할 수 없다.

## 함께 통합한 기존 작업

최신 master 기반 별도 worktree에 온보딩 입력 복원·가입 context·Home 진입 개선과 개발 지침/QA Skills만 통합했다. 전량 매도 이력과 신규 사용자를 구분하고, 다른 탭의 최신 저장 의도를 오래된 인증 응답으로 덮지 않는다. 원래 dirty worktree는 보존한다.

옛 contribution-policy-complete의 방법론/계산 설명 파일들은 대부분 현재 master에 이미 반영됐고, 나머지 오래된 앱 파일은 최신 master를 되돌릴 수 있어 일괄 복사하지 않았다. root의 오래된 추가투입 작업도 보존했다. QA output/log는 제품 커밋에서 제외한다.

## 이번 변경 검증 (2026-09-14)

전체 테스트 2,578개 통과, 인증 경계·tenant writer 등록·활동 SQL·동일 기능 중복·재방문·타 회원 분리·샘플 제외·다른 탭 저장 의도·전량 매도 이력 회귀 포함. 운영 연결 없는 Production 빌드와 린트 통과. 0047은 기존 47개 이력의 hash/시각 및 운영 대상 핀 검증 후 추가 적용했고 FORCE RLS/tenant grant 없음/정책 없음 확인.

실제 브라우저에서 두 자산 입력→첫 분석→새로고침 복원→로컬 인증 연결 실패→입력으로 복귀, Demo→기존 개인 입력 보존을 확인했다. 1440/390px 첫 결과와 1440/390/320px 관리자 실제 컴포넌트 fixture에서 가로 넘침 없음. 관리자 화면 fixture는 실계정 기록이 아니며, 이를 실제 관리자 로그인 검증으로 해석하지 않는다. 실제 이메일 신규가입과 지정 관리자 계정의 로그인은 별도 인증이 필요하다.
