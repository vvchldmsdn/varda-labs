# Cairn Labs

The service display name is **Cairn Labs**. The compact wordmark is lowercase **cairn labs**; page titles use **CAIRN LABS**.

The mark uses three balanced stones with the existing warm accent on the top stone. It represents a wayfinding marker, not an upward-return promise. `BrandLogo` is the shared, accessible SVG and wordmark for public navigation, demo, authentication and the app shell. Its stacked variant fits the narrow desktop sidebar. Browser and home-screen icons use the same original vector geometry.

This is a display-brand change. Existing repository/deployment names, domain, OAuth callbacks, database roles, storage/cookie keys, event names and provenance identifiers retain their established values for compatibility. External provider consent screens and email sender branding require separate configuration and are not changed by a source-code rename. Historical technical documents retain the name used at the time.

Product demo recordings and screenshot fallbacks are captured again from the actual local sample screens after the rename; never relabel an old screenshot with a fabricated dashboard.
