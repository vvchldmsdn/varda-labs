# Beta-only local fonts

Geist Latin variable WOFF2 is the bundled asset in Next.js 16.2.10, node_modules/next/dist/next-devtools/server/font/geist-latin.woff2. Upstream: https://github.com/vercel/geist-font . License: Geist-OFL.txt.

Noto Sans KR variable TTF and OFL obtained from https://github.com/google/fonts/tree/main/ofl/notosanskr . License: NotoSansKR-OFL.txt. Original font bytes retained. Both fonts are served from the local beta asset paths; no runtime or build Google Font requests. Unique family names are applied only to beta scope classes.
